# se-knowledge

A toolkit for building a local, searchable knowledge base from OPSWAT product
documentation. It crawls the public OPSWAT docs site and resource PDFs, cleans
and normalizes the content into Markdown, and maintains a `manifest.json` index
(source URL, product, sha256, size, mtime) suitable for downstream embedding /
retrieval pipelines.

> The crawled content under `docs/` is sourced from publicly available OPSWAT
> documentation and marketing material.

## Requirements

- Node.js 18+
- [Playwright](https://playwright.dev/) (installed via npm) + Chromium

## Setup

```bash
npm install
npx playwright install chromium

# optional: customize paths
cp .env.example .env
```

All path settings are optional — the scripts default to `./docs`, `./pdfs`, and
`./manifest.json`. Override them via the variables documented in `.env.example`.

## Scripts

| Script | Purpose |
| --- | --- |
| `crawl.js` | Full crawl of the OPSWAT docs site → Markdown in `docs/`. |
| `crawl-pdfs.js` | Find, download, and text-extract resource PDFs → Markdown. |
| `sync.js` | Differential re-crawl; applies only new/changed/deleted pages vs. `manifest.json`. |
| `sync-pdfs.js` | Differential PDF sync; downloads only PDFs not already tracked. |
| `build-manifest.js` | Index an existing `docs/` folder into `manifest.json`. |
| `clean.js` | Normalize / de-junk Markdown; optional near-duplicate removal. |
| `validate.js` | Lint Markdown for junk lines and accidental secrets (JWTs, bearer tokens). |
| `schedule-sync.js` | Install/remove macOS `launchd` schedules for the sync jobs. |

### Common usage

```bash
node crawl.js                 # crawl all products
node crawl.js mdcore          # crawl a single product
node build-manifest.js        # (re)build the manifest index
node sync.js --dry-run        # preview a differential sync
node clean.js --dry-run       # preview cleaning
node validate.js              # validate docs

# macOS scheduling (launchd)
node schedule-sync.js         # install schedules
node schedule-sync.js --status
node schedule-sync.js --remove
```

## Repository layout

```
.
├── docs/            # Crawled + extracted Markdown (the knowledge base)
├── logs/            # Sync run logs
├── My POV Docs/     # Proof-of-value working documents
├── *.js             # Crawl / sync / clean / validate / schedule tooling
├── manifest.json    # Index of all docs
└── .env.example     # Optional path configuration
```

`pdfs/` (downloaded PDF binaries) and `node_modules/` are not committed — they
are regenerated by `npm install` and `node crawl-pdfs.js`.

## Configuration

| Variable | Default | Used by |
| --- | --- | --- |
| `SE_DOCS_DIR` | `./docs` | crawl, build-manifest, clean, validate, sync |
| `SE_PDF_DIR` | `./pdfs` | crawl-pdfs, sync-pdfs |
| `SE_PDF_DOCS_DIR` | `./docs/pdfs` | crawl-pdfs, sync-pdfs |
| `SE_MANIFEST` | `./manifest.json` | build-manifest, sync, sync-pdfs |
